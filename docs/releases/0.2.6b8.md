# v0.2.6b8

Added an SD/TF card recording playback entry for the Jumu 2K Smart Camera S1:

- An S1 already added to the integration gets a new “SD Card Playback” camera entity.
- The “ORVIBO Recording Playback” card supports selecting a camera or NVR, searching dates for the current month and clips for a selected day, and playing/stopping at a selected time.
- Added search and playback support for channel 0 on ordinary Meari XTS IPC devices, while retaining existing NVR entities, card type, and service names.

After updating and restarting Home Assistant, choose “S1 SD Card Playback” in the existing playback card, select a date confirmed to contain recordings in the official App, click “Search recordings,” then click a clip to play it. Initial connection may take about a minute. If the card does not list the S1, force-refresh the page. If you previously added the card resource manually, update its entry to:

`/orvibo_smart_control/www/orvibo-smart-control-nvr-card.js?v=0.2.6b8`

This release completes static protocol analysis of the official App. The full Python 3.12 offline suite passed, 698 tests. Real S1 storage-card search and playback still need validation on the device.
Only ordinary time-based playback is implemented; cloud recordings, `record_id` mode, audio, pause, and variable speed are not included.

This is published as an ordinary Release / Latest; `bN` distinguishes development versions.
