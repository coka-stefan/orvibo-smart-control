# v0.2.6b8

巨目 2K 智能摄像机 S1 新增 SD/TF 存储卡录像回放入口：

- 已添加到集成的 S1 会新增“存储卡回放”camera 实体。
- “欧瑞博录像回放”卡片支持选择摄像机或录像机，查询当月日期、当天片段并按时间播放、停止。
- 补齐普通 Meari XTS IPC 通道 0 的查询和播放支持，保留原 NVR 实体、卡片类型和服务名。

更新并重启 Home Assistant 后，在原回放卡片中选择“S1 存储卡回放”，选取官方 App
中确认有录像的日期，点击“查询录像”，再点击片段播放。首次连接可能需要约一分钟。
如果卡片未列出 S1，请强制刷新页面；此前手动添加过卡片资源时，把原条目更新为：

`/orvibo_smart_control/www/orvibo-smart-control-nvr-card.js?v=0.2.6b8`

本版完成官方 App 静态协议分析，Python 3.12 全量离线测试 698 项通过，真实 S1 存储卡查询及播放仍需设备验证。
只实现普通时间回放，暂不含云录像、record_id 模式、音频、暂停及倍速。

本版按普通 Release / Latest 发布，bN 用于区分开发版本。
