# v0.2.6b7

Made the playback card more compact to reduce page height:

- Channel and date appear side by side; the card uses automatic height by default.
- The clip list shows about three rows at most, with overflow scrollable within the list; it collapses automatically after playback starts.
- Search for the current month and specify a time under “More Options”; the player appears above the clip list.
- Narrow screens use a single column; search, clip switching, specified-time playback, and stop remain available.

After updating in HACS, restarting HA, and force-refreshing the browser, the existing card configuration continues to work. If you previously fixed the card's row count manually, set it to automatic height in the layout or add:

```yaml
grid_options:
  columns: 12
  rows: auto
```

Real-browser comparison at 320/430/820px viewports with 256 clips showed no horizontal overflow and kept the list capped at 120px. At 430px, idle card height was about 439→196px, with clips about 699→391px and playback about 923→484px. These measurements used simulated HA services and a player area; actual HA styling and video aspect ratio may differ. Hard-drive recording search and playback still need validation on the user's device. This release includes the previous resource auto-registration fix.

This is published as an ordinary Release / Latest; `bN` distinguishes development versions.
