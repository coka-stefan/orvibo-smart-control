# v0.2.6b7

回放卡片改为紧凑布局，减少展开后的页面占用：

- 通道和日期并排显示，默认自动高度。
- 片段列表最多约三行，多余片段在列表内滚动；开始播放后自动收起。
- 当月查询和指定时间放在“更多选项”中，播放器位于片段列表上方。
- 窄屏使用单列；保留查询、切换片段、指定时间和停止操作。

HACS 更新并重启 HA、强制刷新浏览器后，原卡片配置可继续使用。此前若手动固定过
卡片行数，可在布局中改为自动高度，或添加：

```yaml
grid_options:
  columns: 12
  rows: auto
```

真实浏览器对比320/430/820px视口及256条片段，无横向溢出，列表保持120px限高；
430px视口中空闲高度约439→196px、显示片段约699→391px、播放约923→484px。
数据来自模拟 HA 服务和播放器区域，实际 HA 样式与视频比例可能略有差异；硬盘录像
查询及播放仍需要用户设备验证。包含上一版资源自动注册修复。

本版按普通 Release / Latest 发布，bN 用于区分开发版本。
