## 录像机会话诊断预发布版

新增 `orvibo_smart_control.inspect_video_session` 动作，在现有欧瑞博云连接上检查 Meari 外部授权，返回脱敏的字段存在状态和请求阶段。

**此版本尚未实现实时画面和录像机硬盘历史回放。** 诊断只检查会话响应结构；厂商授权及视频播放仍需真实设备验证。

### HACS 安装

打开 ORVIBO Smart Control → 重新下载，启用预发布版本，选择 `v0.2.6b0`，下载并重启 Home Assistant。

在“开发者工具 → 动作”执行并查看返回结果：

```yaml
action: orvibo_smart_control.inspect_video_session
data: {}
```

只有一个欧瑞博配置项时可留空；多个配置项需提供 `entry_id`。需要现有云连接，纯 LAN 模式不会自动切换。

请提供动作返回的脱敏 JSON，无需账号密码或局域网 IP。
详细说明：[录像机诊断指南](https://github.com/maycode0-0/orvibo-smart-control/blob/v0.2.6b0/docs/nvr-video-diagnostics.md)。

安装包 `orvibo-smart-control.zip` 可供 HACS 使用；手动安装时解压到 `custom_components/orvibo_smart_control/` 后重启。
