## NVR Session Diagnostic Prerelease

Added the `orvibo_smart_control.inspect_video_session` action to inspect Meari external authorization using the existing ORVIBO cloud connection. It returns redacted field-presence status and the request stage.

**This version does not yet implement live video or NVR hard-drive history playback.** Diagnostics only inspect the session response structure; vendor authorization and video playback still need validation on real devices.

### HACS installation

Open ORVIBO Smart Control → Redownload, enable prerelease versions, select `v0.2.6b0`, download, and restart Home Assistant.

In “Developer Tools → Actions,” run the action and inspect its response:

```yaml
action: orvibo_smart_control.inspect_video_session
data: {}
```

Leave this empty if there is only one ORVIBO config entry; if there are several, provide `entry_id`. An existing cloud connection is required; pure LAN mode does not switch modes automatically.

Please provide the redacted JSON returned by the action; there is no need to provide account credentials or a LAN IP.
See the [NVR Diagnostics Guide](https://github.com/maycode0-0/orvibo-smart-control/blob/v0.2.6b0/docs/nvr-video-diagnostics.md) for details.

The `orvibo-smart-control.zip` package can be used by HACS. For manual installation, extract it to `custom_components/orvibo_smart_control/` and restart.
