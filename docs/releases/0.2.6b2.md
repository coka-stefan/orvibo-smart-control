## 录像机通道诊断

在厂商授权和设备列表已取得用户环境正向结果后，新增 `inspect_video_channels` 动作，
读取 NVR 云端通道快照。返回通道编号、原始状态/类型及有限能力码，区分容量、实际条目和缺失数据。

**此版尚未实现实时画面、录像机硬盘片段检索、回放和定位。** 通道批量接口仍需用户环境验证。

`v0.2.6b2` 保留诊断版本后缀，GitHub 按普通 Release 发布，不标记为 Pre-release。
在 HACS 检查更新或重新下载此版本，重启 Home Assistant 后执行：

```yaml
action: orvibo_smart_control.inspect_video_channels
data: {}
```

请提供完整脱敏返回；无需提供账号密码、设备 IP、SN、密钥或原始授权信息。
有多个欧瑞博配置项时提供 `entry_id`。详细说明见[录像机诊断指南](https://github.com/maycode0-0/orvibo-smart-control/blob/v0.2.6b2/docs/nvr-video-diagnostics.md)。

Python 3.12 完整离线测试 543 项通过，包含 22 项新增通道和动作链回归。离线测试不能证明真实设备可以播放。
