## NVR Channel Diagnostics

After receiving positive results for vendor authorization and the device list in the user's environment, added the `inspect_video_channels` action to read an NVR cloud channel snapshot. It returns channel numbers, raw status/type, and a limited set of capability codes, distinguishing capacity, actual entries, and missing data.

**This version does not implement live video, NVR hard-drive clip search, playback, or seeking.** The batch channel API still needs validation in the user's environment.

The `v0.2.6b2` version retains the diagnostic suffix. GitHub publishes it as an ordinary Release, not as a Pre-release.
Check for updates in HACS or download this version again, restart Home Assistant, then run:

```yaml
action: orvibo_smart_control.inspect_video_channels
data: {}
```

Please provide the complete redacted response. There is no need to provide account credentials, device IP, SN, keys, or raw authorization information.
If there are multiple ORVIBO config entries, provide `entry_id`. See the [NVR Diagnostics Guide](https://github.com/maycode0-0/orvibo-smart-control/blob/v0.2.6b2/docs/nvr-video-diagnostics.md) for details.

The complete Python 3.12 offline suite passed, 543 tests, including 22 new channel and action-chain regression tests. Offline tests do not prove that real devices can play video.
