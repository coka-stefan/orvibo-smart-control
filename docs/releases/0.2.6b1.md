## 录像机厂商设备列表诊断

在已取得欧瑞博外部会话的基础上，新增 `inspect_video_devices` 动作，用于验证 Meari 设备列表查询。
返回设备分类数量、连接字段存在状态和有限的原始能力码，不返回账号、token、设备标识、密钥或原始响应。

**此版本仍未实现 NVR 通道参数查询、实时画面和硬盘历史回放。** 厂商列表请求需要实际账号验证，离线测试不能证明设备可播放。

### 安装和诊断

HACS → ORVIBO Smart Control → 重新下载，显示预发布版本，选择 `v0.2.6b1`，下载后重启 Home Assistant。

在“开发者工具 → 动作”执行并提供返回的脱敏 JSON：

```yaml
action: orvibo_smart_control.inspect_video_devices
data: {}
```

有多个欧瑞博配置项时需要 `entry_id`；需要现有云连接。无需提供账号密码或设备 IP。
详细字段说明见[录像机诊断指南](https://github.com/maycode0-0/orvibo-smart-control/blob/v0.2.6b1/docs/nvr-video-diagnostics.md)。

Python 3.11 和 3.12 完整离线单元测试各 520 项通过，新增 21 项设备列表、签名向量、脱敏与异常边界测试。
