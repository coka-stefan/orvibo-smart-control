## NVR Vendor Device List Diagnostics

Added the `inspect_video_devices` action to validate Meari device-list queries using the external ORVIBO session. It returns device category counts, whether connection fields exist, and a limited set of raw capability codes. It does not return accounts, tokens, device identifiers, keys, or raw responses.

**This version still does not implement NVR channel parameter lookup, live video, or hard-drive history playback.** The vendor list request needs validation with a real account; offline tests cannot prove that a device can play video.

### Installation and diagnostics

The `b1` suffix in `v0.2.6b1` distinguishes this diagnostic version. GitHub publishes it as an ordinary Release, not as a Pre-release.

Check for updates in HACS, or open ORVIBO Smart Control → Redownload, select `v0.2.6b1`, download, and restart Home Assistant.

In “Developer Tools → Actions,” run the action and share its redacted response:

```yaml
action: orvibo_smart_control.inspect_video_devices
data: {}
```

If there are multiple ORVIBO config entries, provide `entry_id`; an existing cloud connection is required. There is no need to provide account credentials or a device IP.
For detailed fields, see the [NVR Diagnostics Guide](https://github.com/maycode0-0/orvibo-smart-control/blob/v0.2.6b1/docs/nvr-video-diagnostics.md).

The complete offline unit suite passed on Python 3.11 and 3.12, 520 tests each. This includes 21 new device-list, signature-vector, redaction, and error-boundary tests.
