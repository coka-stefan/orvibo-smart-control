## Specified-Channel Video Connection and Encoded First-Frame Probe

The user confirmed that the NVR cloud returned 8 channels for `v0.2.6b2`, with channel 1 and 3 state set to 1 and P2P capability code 2. This version adds `probe_video_stream`, which actually attempts MsgSvr, TURN, ICE, KCP, and a VVP live request for a specified channel. It returns the connection stage, frame/byte counts, and H.264/HEVC structure information; it does not save video or credentials.

`v0.2.6b3` is an ordinary GitHub Release and is set as Latest, not marked as Pre-release.
After updating in HACS or downloading again, restart Home Assistant and run:

```yaml
action: orvibo_smart_control.probe_video_stream
data:
  device_index: 2
  channel_id: 1
  timeout_seconds: 35
```

Then set `channel_id` to `3` to test the other stream, and provide both complete redacted responses.
Add `entry_id` when there are multiple config entries. The device index refers to the latest device list; confirm it again if the inventory changes.

Media processes are stopped and reclaimed on completion, timeout, cancellation, integration unload, and HA shutdown.
`encoded_video_verified=true` means only that basic parameter-set and encoded-keyframe structures were recognized; `decoded=false` means this action did not validate decoding.
**This version still does not provide a directly viewable live entity or NVR hard-drive history playback.**
If there is no separate video password, it tries the App's default hostKey mode once; it does not automatically try other password combinations.
Compatibility of the Android client version suffix and reference discovery protocol version still needs confirmation in this real-device test.

The full Python 3.12 offline suite passed, 592 tests, covering protocol packets, specified-channel selection, simulated transport through first frame, slow TCP, unrelated STUN packets, hard process timeouts, and cancellation cleanup.
Passing offline tests does not prove playback on an actual device. See the [Diagnostics Guide](https://github.com/maycode0-0/orvibo-smart-control/blob/v0.2.6b3/docs/nvr-video-diagnostics.md) for field details.
