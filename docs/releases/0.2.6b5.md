# v0.2.6b5

Added an “ORVIBO Hard-Drive Recordings” card and a “Hard-Drive Playback” camera for each online NVR channel. Search recording dates for the current month and clips for a selected day, then play a clip or a specified time on the NVR; stop playback when finished. Selecting a new time re-establishes the playback connection. Audio, pause, and variable speed are not supported.

Update and restart HA, refresh the browser, then add the “ORVIBO Hard-Drive Recordings” dashboard card, or use:

```yaml
type: custom:orvibo-smart-control-nvr-card
```

Select a channel and date, then click “Search today.” Enter dates according to the time shown by the NVR. The initial connection may take about a minute. You can also use the `search_hdd_recordings`, `start_hdd_playback`, and `stop_hdd_playback` actions in Developer Tools. If a query fails, share the fixed stage shown in the action response.

Improved live-video retries for slow connections: clears failed prepared connections, warms up already-playing live streams with limited backoff after disconnect, and reuses connections that are still being established. Added redacted `video_diagnostics` connection and media statistics.

The user confirmed that real channel 1 is viewable; channel 3 loads slowly but can also be played after waiting.
**Hard-drive recording search and playback still need validation on real devices.** This implementation is based on the App's native protocol and offline tests; live video does not establish successful hard-drive playback. Ordinary XTS hard-drive recordings are supported, but not the `record_id` mode.

This is published as an ordinary Release / Latest; `bN` only distinguishes development versions.
For detailed steps, see [Hard-Drive Recording Playback](https://github.com/maycode0-0/orvibo-smart-control/blob/main/docs/meari-hdd-playback.md).
