# v0.2.6b5

新增“欧瑞博硬盘录像”卡片和每个 NVR 在线通道的“硬盘回放”摄像头。
可以查询当月录像日期、当天录像片段，点击片段或指定录像机时间回放、停止。
重新选时会重建回放连接；结束后不会自动从起点重播。当前无音频、暂停或倍速。

更新并重启 HA、刷新浏览器后，在仪表盘添加“欧瑞博硬盘录像”卡片，或使用：

```yaml
type: custom:orvibo-smart-control-nvr-card
```

选择通道、日期，再点击“查询当天”。日期按录像机显示时间填写。首次连接可能
需要约一分钟；也可用开发者工具中的 `search_hdd_recordings`、`start_hdd_playback`
和 `stop_hdd_playback` 操作。查询失败时可反馈操作响应中的固定阶段。

改善实时画面的慢连接重试：清理失效预连接，已播放的实时流断线后进行有限退避
预热，复用正在建立的连接。增加脱敏的 `video_diagnostics` 连接/媒体统计。

用户已确认真实通道 1 可看，通道 3 加载慢、等待后也能播放。
**硬盘录像查询和回放仍待真实设备验证**；本版实现依据 App 原生协议及离线测试，
不能把已收到实时画面当作硬盘回放成功。支持普通 XTS 硬盘录像，未含 record_id 模式。

本版按普通 Release / Latest 发布，bN 仅用于区分开发版本。
详细步骤见 [硬盘录像说明](https://github.com/maycode0-0/orvibo-smart-control/blob/main/docs/meari-hdd-playback.md)。
