# v0.2.6b13

优化门锁卡片，让当前锁状态、最近开门人和猫眼抓拍更容易查看。

- **门锁状态**：主锁、门磁和反锁分别显示，已上锁、未上锁、异常和未知使用不同提示；顶部选择有有效读数的电池来源显示电量，0% 仍有效。
- **最近开门**：突出开门人、内开/外开、方式和时间；内开不显示上次外开的姓名或凭据方式。
- **猫眼抓拍**：最新图片单独预览，历史缩略图可横向滑动；点击打开大图，支持上一张/下一张、左右方向键和 Escape，关闭后恢复图片焦点。
- **失败恢复**：抓拍地址最多 4 个并发解析并保持顺序，刷新失败保留已有图片；单张解析失败时复用该图片已有地址，切换设备配置后丢弃旧请求结果。
- **填写与操作**：无关状态更新不重建卡片，相关刷新保留正在填写的内容、焦点、光标和图片滚动位置；折叠区支持键盘，适配手机窄列、深浅色主题和减少动态效果设置。

在 HACS 更新到 **v0.2.6b13**，**重启 Home Assistant 后强制刷新浏览器**，以清除旧卡片脚本缓存。
原有门锁总览卡片与独立临时密码卡片配置可继续使用。

每把锁仍默认保留最近 **30 张**抓拍，可在集成选项“门锁抓拍保留数量”中配置为 **1–500 张**。
卡片 `history_limit` 控制展示数量，磁盘保留数量由集成选项控制。
开门方向仍按密码（含临时密码）、指纹、钥匙、卡片为外开，其余方式及未匹配凭据的门磁开门为内开。
详情见[门锁方向、开锁人及抓拍](https://github.com/maycode0-0/orvibo-smart-control/blob/v0.2.6b13/docs/lock-opening-and-snapshots.md)。

Python 3.12 完整离线测试 **775 项，跳过 2 项，整体通过**；新增电量、内开身份、图片并发、失败保留及旧请求隔离回归。
模拟 Home Assistant 的浏览器验证 **8 组检查通过，无浏览器错误**，覆盖 320/375/768/1024/1440px 布局、
至少 44px 的操作按钮、输入与焦点保留、大图键盘操作、图片失败恢复、空图库和独立密码卡片。
模拟验证不代替真机测试，真实 Home Assistant 的主题、手机显示、云端抓拍和临时密码操作仍需设备确认。
用户原始诊断、模拟预览页面和图片不包含在仓库或安装包中。

本版按普通 Release / Latest 发布，bN 用于区分临时诊断版本，不标记为 Pre-release。
