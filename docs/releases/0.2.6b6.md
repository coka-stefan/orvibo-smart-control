# v0.2.6b6

修复录像卡片资源加载入口，处理“Custom element doesn't exist:
orvibo-smart-control-nvr-card”。存储模式会自动注册仪表盘 JavaScript 模块资源，
更新旧版本地址，并以脚本内容哈希刷新缓存。单个卡片注册失败时继续处理另一张卡片；
仪表盘尚未初始化时在 HA 启动后重试。卡片脚本也支持重复加载。

在 HACS 更新后重启 HA，浏览器使用 Ctrl+F5 强制刷新，再打开原来的卡片配置：

```yaml
type: custom:orvibo-smart-control-nvr-card
```

若仍未显示，可在“设置 → 仪表盘 → 资源”添加
`/orvibo_smart_control/www/orvibo-smart-control-nvr-card.js?v=0.2.6b6`，
类型选“JavaScript 模块”，然后强制刷新。YAML 模式请在资源配置中手动添加模块。

验证包括资源注册和实际 HTTP 文件/MIME 测试、卡片 DOM 测试，以及独立无头 Edge
加载模块、注册组件、重复导入及点击查询后显示片段列表。浏览器测试使用模拟服务，
未连接用户 HA 或真实录像机。硬盘查询与回放仍需设备实测。

本版按普通 Release / Latest 发布，bN 用于区分开发版本。
