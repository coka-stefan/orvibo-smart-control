# v0.2.6b18

Stops the integration from overriding the areas you set in Home Assistant.

- **Your areas stick**: ORVIBO rooms are mapped to Home Assistant areas only for devices that don't have an area yet. Previously, every restart or reload moved each device back to an area named after its ORVIBO room, and recreated that area if you had renamed or merged it (for example, "Main bedroom" reappearing next to a renamed "Bedroom").
- **New devices still get a room**: A newly added device, or one whose area you cleared, is placed in its ORVIBO room's area as before.
- **Option mappings unchanged**: Device area mappings configured in the integration options are still applied.

Update to **v0.2.6b18** in HACS and **restart Home Assistant**.

The full Python 3.12 offline suite passed, **803 tests with 1 skipped**, including new checks that devices with an area keep it and devices without one are placed in their room.

This is published as an ordinary Release / Latest; `bN` distinguishes temporary diagnostic versions and does not mark the release as a Pre-release.
