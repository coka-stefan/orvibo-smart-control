# v0.2.6b14

Fixed card resources remaining on an old version after upgrade and door-lock snapshots failing to load.

- **Automatic resource update**: After Home Assistant finishes starting, it checks the card resource URL again and updates it in place, preventing delayed loading during startup from restoring an older URL. The resource ID and card configuration are preserved; it also retries if the first static registration fails.
- **Snapshots are readable**: Corrected the image parsing API parameters and added an integration-specific authenticated media source. Existing images and recordings in `config/media/orvibo_smart_control/` can be read directly without setting `media_dirs` or moving files.
- **Recording service**: `fetch_video` responses and archived recording cache entries now use the new media reference, consistent with history queries.

Update to **v0.2.6b14** in HACS, **restart Home Assistant, then force-refresh the browser**.
Existing dashboard JavaScript resource entries, door-lock card configuration, and local snapshots can remain.
Each lock still retains the 30 most recent snapshots by default; set **1–500** in the integration options. The card's `history_limit` controls display count.

The full Python 3.12 offline suite passed, **787 tests with 2 skipped**. It covers startup resource URL rollback, registration retry after failure, strict HA media parsing parameters, mapping existing snapshot directories, archive path boundaries, and cached recording references.
Simulated Home Assistant browser checks passed **8 groups with no browser errors**.
Local reproduction of startup races and simulated checks do not replace real-device testing; resource updates after a real upgrade, authenticated image reads, and new cloud snapshots still need device confirmation. The user's original diagnostics, screenshots, and local verification tools are not included in the installation package.

This is published as an ordinary Release / Latest; `bN` distinguishes temporary diagnostic versions and does not mark the release as a Pre-release.
