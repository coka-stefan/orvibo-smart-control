# v0.2.6b16

Fixes doubled entity names in Home Assistant.

- **No more doubled names**: The main entity of each light, cover, switch, climate (fan coil and floor heating), and ventilation fan device showed the device name twice, for example "Roller Blinds Roller Blinds" or "Kitchen pendant Kitchen pendant". It now shows only the device name.
- **Feature entities unchanged**: Secondary entities keep their feature names, for example "Battery", "Motion", "Drying rack", "Power", or "Light" on a clothes horse.
- **Diagnostic sensors**: The "Transport path" and "Camera SDK hint" sensors now show their translated names instead of only the device name.
- **IDs stay stable**: Entity IDs and unique IDs do not change, so automations, dashboards, and history keep working. Names you set yourself in Home Assistant are kept.

Update to **v0.2.6b16** in HACS and **restart Home Assistant**.

The full Python 3.12 offline suite passed, **797 tests with 1 skipped**, including new naming checks for primary, secondary, and translated entities.
The displayed names still need confirmation in a real Home Assistant instance.

This is published as an ordinary Release / Latest; `bN` distinguishes temporary diagnostic versions and does not mark the release as a Pre-release.
