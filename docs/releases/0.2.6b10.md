# v0.2.6b10

门锁方向改为四类凭据规则：

- **外开**：密码（含临时密码）、指纹、钥匙、卡片；胁迫密码、指纹和卡片归对应类别。
- **内开**：其余开锁方式，包括人脸、其他/未知方式，以及只有门磁打开但没有匹配到四类外开凭据的情况。
- 内开显示“人员未知”，不再继承前一次外开的用户或姓名；门磁再次开门、过期和重复推送也不会复用上次人员。

这是按用户要求采用的方向推断策略，不代表固件明确上报了内开；真实设备的事件时序及身份编号仍需验证。

在 HACS 更新到 **v0.2.6b10** 后，**重启 Home Assistant**。姓名继续在集成选项
“锁用户映射”中逐行填写 `用户ID=姓名`，不加括号和逗号；用户ID应对应门锁上报的授权编号。
多把锁或同编号对应不同凭据时，可使用 `设备ID/用户ID=姓名` 或
`设备ID/fingerprint/用户ID=姓名`。已有映射无需因本次方向规则更新而重新填写。

抓拍继续默认每把锁保留最近 30 张，可在“门锁抓拍保留数量”配置为 1–500 张。

Python 3.12 完整离线测试 747 项，跳过 2 项，整体通过。门锁实机行为仍待验证。

详细说明见[门锁方向、开锁人及抓拍](https://github.com/maycode0-0/orvibo-smart-control/blob/v0.2.6b10/docs/lock-opening-and-snapshots.md)。
