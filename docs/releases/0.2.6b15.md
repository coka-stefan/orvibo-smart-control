# v0.2.6b15

Adds roller blinds and curtains driven by the ORVIBO multifunction relay controller.

- **Relay curtain controller**: Devices with `deviceType=42` and `subDeviceType=-2` (catalog name "multifunction controller") are now `cover` entities with open, close, and stop. They were previously listed as "recognized; not yet supported".
- **No position feedback**: The controller always reports position 0, so the cover has an assumed state and no position slider; both directions stay available.
- **Direction follows the app**: Open and close send the same order as the matching learned key in the ORVIBO app, so a direction swapped in the app is honored in Home Assistant.
- **Cloud control**: Commands use the cloud connection; local LAN control for this type is not yet verified.
- This build also includes the English translation of the UI, logs, and documentation, and the initial-setup discovery fallbacks.

Update to **v0.2.6b15** in HACS, **restart Home Assistant, then force-refresh the browser**. If the controller was deselected earlier, select it again in the integration options.

The full Python 3.12 offline suite passed, **792 tests with 1 skipped**, including key-order mapping, classification, and control routing for the relay controller.
The controller was classified and its cover entity created in a local Home Assistant instance; open, close, and stop direction on the real motor still need device confirmation.

This is published as an ordinary Release / Latest; `bN` distinguishes temporary diagnostic versions and does not mark the release as a Pre-release.
